# Week 5 Assignment: Hands-On Lab — Countdown, Guessing Game & Loop Patterns

This repository contains my Week 5 Python assignment for the Power Learn Project.

- `countdown.py` — Uses a while loop to count down from a number entered by the user and prints "Blast off!".
- `guess_game.py` — A number guessing game that uses a while loop, conditionals, hints, and an attempt counter.
- `spell_it_out.py` — Uses for loops to print the letters of a word individually and then number each letter.
- `screenshots/` — Contains screenshots showing each program running.

## When to use a while loop instead of a for loop

I would use a while loop when I do not know exactly how many times the loop should run. It is useful when the program needs to continue until a condition changes, such as when a user gives the correct answer in a guessing game. I would use a for loop when I already know what data I want to go through or how many times I want to repeat an action.
